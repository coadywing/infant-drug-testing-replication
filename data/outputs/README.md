# data/outputs

Intermediate data files written by the scripts in `code/`. All are derived from the restricted
INPC data and are not distributed. Running `code/main.R` creates them in this folder.

Scripts 01–14 build the analytic sample step by step. The final analytic file,
`final_analytic_sample_with_infant_char_for_reg.csv`, is written by script 15 and read by the
table and figure scripts (16–34). See `FILE_PIPELINE.md` for the full sequence.
